# Sports Club Management System

This repository contains a sports club management application built with vanilla PHP, MySQL, and Bootstrap.

For full documentation, setup instructions, architecture details, and feature descriptions, see:

- `DOCUMENTATION.md`

If you want a quick start:
- Import `database.sql` into your MySQL server
- Import `league_team_schema.sql` to add leagues, teams, and registrations
- Copy `.env.example` to `.env` and fill in your database/API values
- Open `http://localhost/sports_club_management/public/index.php`
